# Sous Couvert — mentions publiques

Ce dépôt ne sert qu'à héberger, via GitHub Pages, la politique de confidentialité de
l'application **Sous Couvert** : le Play Store exige une URL publique, et le code du jeu reste
privé.

- Page publiée : <https://tengojul.github.io/souscouvert-pub/>
- Contenu : `index.html`, page autonome, sans police, feuille de style ni script externes — la
  page affirme qu'aucune donnée ne quitte l'appareil, elle ne peut pas charger de tiers.

`index.html` est une copie. La version de référence vit avec les sources du jeu ; toute
modification s'y fait d'abord, puis se recopie ici.
